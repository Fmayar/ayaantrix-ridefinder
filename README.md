# AYAANTRIX RideFinder

A mobile and web rideshare discovery and comparison platform developed by AYAANTRIX Technologies LLC.

## Platforms
- iOS and Android: React Native + Expo
- Website: Next.js
- Backend: Java Spring Boot
- Database: PostgreSQL

## Initial Market
Austin, Texas, USA

## Project Status
M0/T01 — Initial project setup

## Goal
Help customers discover transportation providers, compare authorized fare and pickup estimates, and continue to official booking applications.
